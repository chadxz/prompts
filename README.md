# Prompts

This is the agent setup I use day to day. It includes personal instructions,
skills, small tools, and configuration for Codex, Claude Code, Pi, and a few
related workflows.

The best experience comes from owning your setup and adapting it to your
preferences and practices. Borrowed skills can feel harder to change because
someone else wrote them, even when they no longer fit. Agents make those changes
cheap. If something here helps, use it, modify it, and make it yours.

Most of the reusable pieces live in [skills](skills). The repository also
contains [Pi extensions](pi/extensions) and [wt-stack](apps/wt-stack), a tool
for managing stacked changes across sibling Git worktrees. The setup scripts
reflect my machines and preferences, so read them before running them.
