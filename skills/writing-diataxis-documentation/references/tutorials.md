# Tutorials

Need: help a learner acquire skill through action. The tutorial uses an output
to create the learning experience.

- Treat the tutorial as a lesson. The tutor owns the learner's safe, successful
  progress.
- Create a contrived, controlled setting and one end-to-end path. Remove choices
  and unexpected branches.
- Lead through concrete actions in small steps. Produce visible results early
  and often.
- State expected results and point out what the learner should notice. This
  substitutes for the absent teacher's feedback.
- Make useful actions repeatable where possible. Repetition builds familiarity
  and confidence.
- Keep explanation, abstraction, and reference detail brief. Link to the full
  material.

## Language

- Use "we" to affirm the tutor and learner relationship.
- Open with "In this tutorial, we'll ..." and name the accomplishment. Avoid
  promises about what the reader "will learn."
- Sequence actions without ambiguity: "First ... Now ... Now that ..."
- State what the output should look like.
- Use "Notice ...", "Remember ...", and "Let's check ..." to direct attention
  and confirm progress.
- Give only the explanation needed to keep moving: "We do X before Y because Z.
  See the explanation for details."
- Close by naming what the learner built or accomplished.

Reject a draft that merely gets a task done. Test the complete experience with
the stated starting conditions and, when possible, a representative learner.
