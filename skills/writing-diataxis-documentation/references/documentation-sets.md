# Documentation sets

Read this only for architecture, migration, or mixed-content review.

## Structure

The four forms map user needs. They don't require a four-folder layout. Users
can enter anywhere and move between needs in any order. Separate the forms, then
connect them with links where the need changes.

Skip empty quadrant sections and top-down reorganizations. Improve from the
inside out:

1. Choose one small existing unit.
2. Use the compass to identify the need it serves.
3. Make one change that serves that need better.
4. Repeat and let the larger structure emerge.

When content blurs, classify at sentence level. Move useful intrusions into the
correct form and link them.

Diataxis addresses deep quality: fit to human needs, flow, and anticipation. It
can expose gaps in functional quality. Check accuracy, completeness,
consistency, and precision separately.
